# Акриловые пластмассы

## Типы
- Горячей полимеризации: основной выбор для базисов, низкая остаточная мономерность.
- Холодной полимеризации: для починок и временных протезов.
- Термопластичные (нейлон): гибкие, требуют специальной литьевой установки.

## Правила работы
1. Пропорция порошок:мономер — по инструкции, обычно 2:1 по объёму.
2. Тестообразная стадия — когда масса перестаёт липнуть к стенкам ёмкости.
3. Мономер — токсичен и летуч: работать в вытяжном шкафу, использовать перчатки.
4. Хранить в прохладном месте, мономер плотно закрывать.

## Усадка
Около 0,5 % линейно при правильной полимеризации.
