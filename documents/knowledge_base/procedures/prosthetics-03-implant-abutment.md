# Индивидуальный абатмент

## Порядок работы
1. Проверьте комплектность: аналог имплантата, трансфер, слепочная система и тип внутреннего соединения.
2. Модель с десной (маска из силикона) изготавливается по оттиску с аналогом.
3. Моделирование абатмента в CAD с учётом профиля прорезывания, высота десны — не менее 1,5 мм.
4. Фрезерование из титана или циркония; на титан-циркониевое соединение ставится титановая база.
5. Винт затягивается ключом с моментом, указанным производителем (обычно 20–35 Н·см).
6. Окончательная фиксация реставрации на абатмент выполняется по инструкции к цементу.

## Критерий качества
Плотная посадка без качания, отсутствие зазора на стыке с аналогом.
