# Загипсовка в артикулятор

## Порядок работы
1. Проверьте прикусной регистрат: он не должен иметь перфораций и должен однозначно позиционировать модели.
2. Верхняя модель устанавливается по лицевой дуге, при её отсутствии — по среднестатистическим значениям.
3. Фиксируйте модель гипсом, избегая нагрузки на штифт до полного схватывания.
4. Нижняя модель загипсовывается по регистрату, высота прикуса контролируется по резцовому штифту.
5. После схватывания проверьте окклюзионные контакты артикуляционной бумагой 40 мкм.

## Критерий качества
Окклюзионная высота соответствует регистрату, модели не смещаются при закрывании артикулятора.
